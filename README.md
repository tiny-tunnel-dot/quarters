# quarters

The dev arcade — Tony's project roster as a retro CRT arcade page. Single
self-contained `index.html` (fonts and data inlined, no build, no deps).

- Open locally: `open index.html`
- Also published as a Claude artifact: https://claude.ai/code/artifact/2f098c99-50e1-41fc-95f1-3cc4f75c1a1e
- Data (LOC / PRs / commits / heatmap) is a snapshot baked in at build time —
  ask Claude Code to "re-tally quarters" to refresh it.
